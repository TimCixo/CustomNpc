# Anvil Ten Lvl

Блок anvil, що значення зачарування книг до 10 рівня за класичною логікою Minecraft.

## Мерджування

**Логіка:**
- `5 + 5 = 6` (однакові чари: макс + 1, максимум 10)
- `Sharpness 5 + Looting 3` (різні чари: просто додаються)

## Використання

1. Грав цьюму ПКМ по ковадлу з **першою** зачарованою книгою (повідомлення: "First enchanted book added.")
2. Грав цьюму ПКМ по ковадлу з **другою** зачарованою книгою
3. Мерджена книга видається в інвентар

## Примітки

- Обидві книги мають містити зачарування (не порожні)
- Результат видається тільки якщо вільне місце в інвентарі
- Блок використовує `tempdata` для збереження першої книги (очищується після мерджування)
