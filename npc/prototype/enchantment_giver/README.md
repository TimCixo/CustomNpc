# Enchantment Giver

Prototype NPC that applies all possible enchantments to an item at max level.

## Usage

- Right-click the NPC while holding an item in main hand.
- The NPC will enchant the item with all compatible enchantments at their maximum levels.

## Notes

- Only enchantments that can be applied to the item type will be added.
- Uses Minecraft's EnchantmentHelper for compatibility.
