# Move Tutor

NPC-пакет для обучения Cobblemon-покемона движениям через купон `move_teach_coupon`.

## Hooks

- `hooks/interact.js` -> `interact`

## Рекомендуемый layout

Этот пакет уже приведён к каноническому layout для `github_npc_loader`:

```text
move_tutor/
  README.md
  hooks/
    interact.js
```

Для загрузки через предмет указывай URL папки `move_tutor`, а не более широкой директории.

Пример:

```text
https://github.com/<owner>/<repo>/tree/main/npc/finished/move_tutor
```

## Что делает

- Проверяет, что у игрока в основной руке есть купон с `coupon_type = move_teach_coupon`.
- Открывает GUI выбора покемона из текущей пати.
- После выбора открывает GUI со списком доступных для изучения движений.
- Фильтрует уже изученные движения.
- При выборе движения запускает серверную команду `/teach <player> <slot> <move>`.
- После успешного вызова списывает один купон из основной руки.

## Ограничения

- Пакет рассчитан только на hook `interact`.
- GUI-логика живёт в том же hook-файле через `customGuiScroll`.
- Если у игрока нет корректного купона в основной руке, NPC не откроет обучение.
